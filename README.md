# DataParl' – Contributions & Feedback

Ce dépôt sert **uniquement** à :
- signaler des erreurs de données
- proposer des améliorations
- discuter de la méthode
- suivre la roadmap publique de DataParl'

> **Le code source de DataParl' n’est pas public.**  
> Ce dépôt est un espace de contribution et de transparence.

## Liens utiles

- Site : [dataparl.fr](https://www.dataparl.fr)
- Méthode : [dataparl.fr/methode](https://www.dataparl.fr/methode)
- Sources : [dataparl.fr/methode/sources](https://www.dataparl.fr/methode/sources)
- API : [api.dataparl.fr](https://api.dataparl.fr)
- Jeux de données : [data.gouv.fr/organizations/dataparl](https://www.data.gouv.fr/organizations/dataparl)

## Comment contribuer

| Type | Comment faire |
|------|---------------|
| **Erreur de données** | Ouvrir une issue avec le label `erreur-données` + lien vers la fiche concernée |
| **Amélioration / idée** | Ouvrir une issue avec le label `amélioration` |
| **Question sur la méthode** | Label `méthode` |
| **Demande de documentation** | Label `documentation` |

Merci de toujours indiquer :
- le lien de la page concernée
- ce qui est incorrect ou ce que vous proposez
- si possible la source officielle qui contredit (ou complète) la donnée

## Roadmap

La roadmap publique est visible dans les [Milestones](../../milestones) et les issues labellisées `roadmap`.
